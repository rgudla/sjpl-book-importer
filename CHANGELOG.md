## 0.1.0 - 2026-08-27

Initial public release.

- Import book metadata from Amazon.
- Import book metadata from Walmart.
- Import book metadata from Barnes & Noble.
- Import book metadata from Bookshop.org.
- Import book metadata from ThriftBooks.
- Import book metadata from Book Outlet.
- Open the SJPL purchase suggestion form in a new tab and autofill supported fields.
- Keep the final SJPL submission manual.
- Support configurable preferred library and per-bookseller source labels.
- Add a cleaned source product URL to the SJPL Comments field.
- Avoid modifying SJPL's validation / anti-spam `Name` field.
- Intentionally leave Barnes & Noble Author / Performer and Publisher blank to avoid unreliable metadata.
